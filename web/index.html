AudioVAE source

Upstream publishes the AudioVAE only as audiovae.pth, a Python pickle this build cannot read, and no .safetensors version is hosted anywhere public. Convert it once with the convert_audiovae example, then either point at a CORS-friendly host (a Hugging Face repo works — GitHub release assets do not) or just pick the local file: it never leaves this tab.
